# 단거리 스톱워치

단거리 달리기 기록 측정용 모바일 웹앱입니다. https://choiteacher.github.io/stop-watch/

- '카운트 시작' → "제자리에" → "차렷" → 출발 버저 (신호 간격 0.5~1.5초 랜덤)
- 블루투스 스피커 송출 지연을 보정해 버저가 실제로 울리는 순간 스톱워치 시작 (⚙에서 0~600ms 조정, 기본 250ms)
- '기록'으로 도착 기록 최대 10개, '중지' 후 '초기화'
- 음성: Microsoft Edge 신경망 TTS(ko-KR-InJoonNeural, 빠르고 낮고 강하게)로 생성, 버저: 전자 출발 신호기 음을 Web Audio로 합성
